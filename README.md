## Why laravel-cream?

> Laravel, creamed. - built for vibe coders and web developers who ship with taste.

Laravel cream - elegant PHP starter with cream views and auth. This template keeps the cream aesthetic - stone, ink, and low contrast - and ships with a clean structure you can vibe-code on top of.

## Stack

- **Language:** php
- **Style:** Tailwind cream tokens, Biome where applicable
- **Quality:** CI, lint, and a minimal test harness

## Get started

```bash
git clone https://github.com/knownasrazi/laravel-cream.git
cd laravel-cream
```

Language-specific quick start is inside.

## Structure

```
laravel-cream/
  README.md
  LICENSE
  src/ or app/  # language entry
```
